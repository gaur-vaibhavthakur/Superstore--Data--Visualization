#  Superstore Dashboard – Task 2 (Data Analyst Internship)

##  Objective
Create compelling visualizations and generate key business insights from the Superstore dataset using Power BI.

---

## Files Included

1- README.md
2- Superstore_raw(raw_dataset)
3- Superstore_data_cleaning_.ipynb – Data preprocessing in Python
4- Superstore_cleaned.csv – Cleaned dataset
6- Insights_Report.pdf – (Summary report with dashboard mockup and insights)
7- dashboard.png – (Visual mockup of the dashboard)

---

##  Dashboard Highlights
1- KPIs: Total Orders, Quantity, Avg. Unit Price, Avg. Days to Ship
2- Sales Trend: Monthly performance overview
3- Regional Analysis: Orders and delivery metrics by region
4- Product Insights: Category & Sub-Category breakdown
5- Customer Segments: Performance by segment
6- Shipping Methods: Analysis by Ship Mode

---

##  Key Insights
1. The West region had the highest number of orders.
2. 'Technology' is the best-performing product category.
3. Average shipping time is ~3.5 days across all orders.
4. Most customers prefer Standard Class shipping.
5. Consumer segment is the most active and profitable.



# Tools Used
1- Python (for data cleaning)
2- Power BI (visuals)
